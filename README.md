# 🌦️ Weather App

A simple and responsive weather application that provides real-time weather updates for any city using a weather API.

---

## 🚀 Live Demo

👉 https://aasmaan.netlify.app/

---

## 📌 Features

- 🌍 Search weather by city name  
- 🌡️ Displays temperature, humidity, and weather conditions  
- ⛅ Real-time data fetched from API  
- 📱 Fully responsive design
